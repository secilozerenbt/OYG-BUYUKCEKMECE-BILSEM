# Öğrenci Rehberi

Bu rehber, ödev şablonunu kendi hesabınıza almanız ve bilgisayarınızda yazdığınız kodları kendi deponuza yüklemeniz içindir. Git komutlarını bilmeniz gerekmez.

## 1. Kendi ödev deponuzu oluşturun

1. [OYG-BUYUKCEKMECE-BILSEM şablonunu açın](https://github.com/secilozerenbt/OYG-BUYUKCEKMECE-BILSEM) ve GitHub hesabınızla giriş yapın.
2. **Use this template → Create a new repository** seçeneğini kullanın.
3. **Owner** alanında kendi hesabınızı seçin.
4. Depo adını `python-for-dongusu-odevim` olarak yazın.
5. Görünürlüğü **Private** seçin ve **Create repository from template** düğmesine basın.
6. Sayfanın üstünde kendi kullanıcı adınızın yazdığını kontrol edin. Bundan sonraki yüklemeleri bu depoya yapacaksınız.

Bu yöntemle öğretmeninizin şablonundaki dosyalar kendi bağımsız deponuza kopyalanır.

## 2. Öğretmeninize erişim verin

1. Kendi ödev deponuzda **Settings** sekmesini açın.
2. **Access** bölümünde **Collaborators** veya **Collaborators & teams** alanını bulun.
3. **Add people** düğmesine tıklayın.
4. **`secilozerenbt`** kullanıcı adını yazın ve öğretmen hesabını seçerek davet gönderin.
5. Kendi deponuzun bağlantısını öğretmeninize sınıfta kullanılan iletişim kanalından gönderin.

Özel bir depoyu görüntüleyebilmesi için öğretmeninizin daveti kabul etmesi gerekir. Yalnızca bağlantıyı göndermek erişim sağlamaz.

## 3. Dosyaları bilgisayarınıza indirin

1. Kendi deponuzun **Code** sekmesine dönün.
2. **Code → Download ZIP** seçeneğiyle dosyaları indirin.
3. ZIP dosyasını bir klasöre çıkarın.
4. VS Code’da **File → Open Folder** seçeneğiyle bu klasörü açın.

Python ve VS Code’un Python desteği bilgisayarınızda kurulu olmalıdır. Derste kullandığınız çalışma ortamını kullanabilirsiniz.

## 4. İlk çözümleri ve tekrarları yazın

1. `README.md` içindeki dört soruyu okuyun.
2. `ilk-cozum` klasöründeki ilgili `.py` dosyasını açın ve kodunuzu yazın.
3. Dosyayı kaydedip derste öğrendiğiniz yöntemle çalıştırın. VS Code’da **Run Python File in Terminal** seçeneğini kullanabilirsiniz.
4. Sonucu kontrol ettikten sonra aynı soruyu `tekrarlar/tekrar-1` klasöründeki ilgili dosyaya, çözümü kopyalamadan yeniden yazın.
5. Aynı çalışmayı `tekrar-2`, `tekrar-3`, `tekrar-4` ve `tekrar-5` için de yapın.
6. Bu işlemleri dört soru için tamamlayın. Her dosyayı ayrı ayrı çalıştırın.

Dosyalar yalnızca açıklama satırları içerir. Bu hâlleriyle çalıştırıldıklarında sonuç göstermemeleri normaldir; çözüm kodlarını siz yazacaksınız.

## 5. Çalışmalarınızı GitHub’a yükleyin

1. Tarayıcıda **kendi deponuzun** ana sayfasını açın.
2. **Add file → Upload files** seçeneğine tıklayın.
3. Bilgisayarınızdaki `ilk-cozum` ve `tekrarlar` klasörlerini, ayrıca tamamladığınız `TESLIM.md` dosyasını yükleme alanına sürükleyin.
4. Dıştaki ZIP klasörünü değil, içindeki bu iki klasörü ve teslim dosyasını seçin. Böylece dosyalar şablondaki yerleriyle eşleşir.
5. Kaydetmeden önce listede `ilk-cozum/soru1_sayilarin_toplami.py` ve `tekrarlar/tekrar-1/soru1_sayilarin_toplami.py` gibi yolların göründüğünü kontrol edin.
6. Değişiklik açıklamasına `For döngüsü ödevini tamamladım` yazın ve **Commit changes** ile kaydedin. Arayüz yeni dal seçeneği gösterirse kendi deponuzun mevcut ana dalına kaydetmeyi seçin.
7. Yükleme bittikten sonra bir ilk çözüm dosyasını ve bir tekrar dosyasını açıp yazdığınız kodların göründüğünü kontrol edin.

Çalışmanız devam ediyorsa yalnızca değiştirdiğiniz dosyaları da yükleyebilirsiniz. ZIP dosyasını yüklemek yerine `.py` dosyalarını klasörleriyle birlikte yükleyin; böylece öğretmeniniz kodları doğrudan okuyabilir.

## 6. Tesliminizi bildirin

`TESLIM.md` kontrol listesini doldurun. Öğretmeninize kendi deponuzun bağlantısını göndererek çalışmanın tamamlandığını bildirin. Depo bağlantısı, adres çubuğundaki kendi kullanıcı adınızı ve depo adınızı içeren bağlantıdır.
